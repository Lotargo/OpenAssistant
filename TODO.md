# TODO — Desktop AI Assistant Overlay

Десктопный ассистент-оверлей для собеседований, лайв-кодинга и рабочих митов на базе **Rust + Tauri v2 + Vanilla JS/CSS/HTML** и модели **`gemini-robotics-er-2-streaming-preview`**.

---

## Первый этап — desktop foundation

Каркас Tauri, UI, настройки внешнего вида, потоковый парсер и нативные команды реализованы. Галочки ниже отмечают наличие реализации; ручная проверка Windows остаётся в финальном QA. Gemini Live, аудио и передача кадров ещё не подключены.

Визуальные решения сверяются с `DESIGN.md` и `ui-samples/`. Уточнения к раннему плану: нижняя панель, порядок экран → микрофон → переподключение → настройки → замок, ровно пять кнопок, без кнопки копирования и отдельного индикатора статуса.
