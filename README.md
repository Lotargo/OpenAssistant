# OpenAssistant

Десктопный ассистент на Rust + Tauri v2 с полупрозрачным оверлеем, голосовым вводом и агентом Codex. Код, команды, поиск и инструменты выполняет установленный Codex через `app-server`; вход — через аккаунт ChatGPT в Codex. Полей для API-ключей и подключений сторонних провайдеров нет.

## Что работает

- Текстовые задачи Codex: чтение и изменение файлов выбранного проекта, команды, доступные Codex инструменты и веб-поиск.
- Потоковые ответы: Markdown в текстовом режиме, код слева и пояснения справа, безопасный HTML и подсветка Shiki.
- Выбор рабочей папки, модели из каталога установленного Codex и поддерживаемого уровня рассуждения.
- До трёх одновременных задач, журнал действий, переключение между результатами и отмена.
- Запросы разрешений и уточняющие вопросы Codex в настройках. Ответ передаётся в исходную сессию; приложение не подтверждает действия автоматически.
- Голосовой канал OpenAI Realtime через авторизацию Codex: непрерывный микрофон, ответ после паузы, транскрипция и передача поручений агенту.
- Системный микрофон по умолчанию и смена устройства во время активной сессии.
- Настройки оформления, прозрачный оверлей, системный трей, горячие клавиши, независимая прокрутка и сохранение геометрии.

Микрофон и соединение с моделью запускаются по действию пользователя. Если голосовой канал недоступен, текстовые задачи Codex продолжают работать.

**Захват системного звука и передача изображения экрана пока не реализованы.** Их элементы в настройках явно показывают недоступность. На Windows используется системное исключение окна из поддерживаемых способов захвата; поведение зависит от приложения трансляции.

## Авторизация

1. Установите Codex CLI и войдите в него через ChatGPT:
   ```powershell
   codex login
   ```
2. Откройте OpenAssistant → настройки → **Агент**.
3. Выберите рабочую папку и подключитесь. Модели и уровни рассуждения загружаются из установленного Codex.
4. Введите задачу либо включите микрофон на нижней панели.

Приложение запускает нативный бинарник Codex без shell-обёртки и проверяет, что активен ChatGPT-аккаунт. Провайдер агентной сессии — OpenAI. Переменные `OPENAI_API_KEY` и `CODEX_API_KEY` не передаются дочернему процессу.

Голосовой адаптер использует OAuth Codex для получения короткоживущего секрета Realtime. Учётные данные читаются только внутри Rust; они не отправляются в WebView, не сохраняются в настройках приложения и не включаются в диагностические сообщения. Доступность Realtime определяется ответом сервиса для текущего аккаунта. При отказе остаётся доступен текстовый Codex.

Текстовый агент использует механизм авторизации самого Codex. Для Realtime нужен доступный локальный OAuth credential store Codex; если его формат или доступность изменятся, ошибка отображается в настройках голосового канала.

## Запуск в Windows

Нужны Node.js 22.12+, Rust, Microsoft C++ Build Tools и WebView2.

```powershell
npm ci
npm run desktop:dev
```

Сборка:

```powershell
npm run desktop:build
```

Результат: `src-tauri/target/release/open-assistant.exe`. Установщик не создаётся.

Для запуска собранного приложения из корня проекта:

```powershell
.\src-tauri\target\release\open-assistant.exe
```

Настройки сохраняются через `tauri-plugin-store` в каталоге данных приложения. Настройки агента и оформления отделены от учётных данных Codex.

## Управление

На нижней панели остаются ровно пять кнопок: экран, микрофон, переподключение, настройки, блокировка прокрутки. Задачи, модель, разрешения и журнал находятся внутри настроек; дополнительных панелей управления поверх ответа нет.

| Сочетание | Действие |
| --- | --- |
| `Ctrl+Shift+Space` | Показать / скрыть окно |
| `Ctrl+Shift+M` | Включить / выключить микрофон |
| `Ctrl+Shift+L` | Заблокировать / разблокировать ручную прокрутку |
| `Ctrl+Shift+S` | Показать сообщение о недоступном захвате экрана |

Переподключение завершает текущую сессию. Отдельную задачу можно отменить на вкладке агента. При выходе из приложения закрываются голосовой канал и запущенный им процесс Codex.

## Браузерный просмотр интерфейса

```powershell
npm run dev
```

Откройте [http://127.0.0.1:1420](http://127.0.0.1:1420). Браузерный просмотр предназначен для дизайна и тестирования раскладок; подключение Codex и нативные функции доступны в приложении Tauri.

| Адрес | Состояние |
| --- | --- |
| `/?demo=text` | Текстовый ответ |
| `/?demo=code` | SQL-код и пояснения |
| `/?demo=settings` | Настройки поверх ответа |
| `/?demo=stream` | Потоковый демонстрационный ответ |

Демонстрационные данные — локальные фикстуры, без запросов к модели.

## Архитектура

| Путь | Назначение |
| --- | --- |
| `crates/assistant-core/src/auth.rs`, `provider.rs` | OAuth и подключение Realtime |
| `crates/assistant-core/src/codex.rs` | JSON-RPC транспорта Codex app-server через stdio |
| `crates/assistant-core/src/agent.rs` | Задачи, события, подтверждения, вопросы и отмена |
| `crates/assistant-core/src/bridge.rs`, `session.rs` | Голосовой протокол и общий жизненный цикл сессии |
| `src-tauri/src/assistant.rs` | Tauri IPC, ограниченные очереди, изоляция сессий и завершение |
| `src-tauri/src/window_stealth.rs` | Окно, фокус, размеры, исключение из захвата и Windows wheel hook |
| `src/js/session-transport.js`, `bridge.js` | Native Channel, настройки и состояние интерфейса |
| `src/js/microphone.js` | Захват микрофона, выбор устройства и PCM 24 кГц |
| `src/js/markdown-stream.js`, `renderer.js` | Потоковый Markdown, разделение кода и пояснений |
| `src/js/settings-modal.js` | Настройки, задачи и диалоги разрешений |

Ядро не зависит от HTTP-сервера и интерфейса. Между Rust и WebView проходят только команды, аудиофрагменты и безопасные события. Локальный порт для работы приложения не открывается. Устаревшие события и команды прошлой сессии не могут изменять новую.

## Проверки

```powershell
npm test
npm run build
npm run test:e2e
cargo test --manifest-path crates/assistant-core/Cargo.toml
cargo test --manifest-path src-tauri/Cargo.toml
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings
```

Браузерные тесты используют управляемый Tauri IPC mock и не обращаются к моделям. Rust-тесты проверяют протокол, валидацию, авторизацию, ограничения очередей, отмену и работу дочернего mock app-server. Проверки настоящего Codex и Realtime запускаются отдельно и не входят в обычный тестовый прогон.

GitHub Actions отключены. Проверки и сборка выполняются локально.
